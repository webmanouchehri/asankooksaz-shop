
# asankooksaz-shop
# آسان‌کوک ساز | فروشگاه اینترنتی

نمونه‌کار طراحی و پیاده‌سازی فروشگاه اینترنتی با وردپرس بهمراه کدنویسی 

🔗 **مشاهده‌ی سایت:** [asankooksaz.com](https://asankooksaz.com/)

## درباره‌ی پروژه
فروشگاه اینترنتی تخصصی محصولات آسان‌کوک ساز (گوشی‌های مکانیکی تار، سه‌تار، تنبور و کمانچه و گیتار و ...).

## ابزارهای استفاده‌شده
- WordPress
- Elementor
- Elementor pro
- WooCommerce
- JetEngine
